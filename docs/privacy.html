서비스명 StreamKit+
제작 izunyadev
시행일 2026년 9월 23일

StreamKit+는 여러 방송 플랫폼의 방송 정보와 채팅을 한 곳에서 다루는 Windows 프로그램입니다. 이 방침은 프로그램이 어떤 정보를 다루고 어디에 두는지 설명합니다.

제작자는 아무것도 수집하지 않습니다

StreamKit+는 제작자가 운영하는 서버가 없습니다. 프로그램이 만들어내는 정보는 사용자 PC를 벗어나 제작자에게 전달되지 않습니다.

이용 기록을 모으는 분석 도구나 추적 코드도 넣지 않았습니다. 광고도 없습니다.

PC에 저장되는 정보

아래 정보는 사용자 PC에만 저장되며 제작자는 볼 수 없습니다.

로그인 토큰 플랫폼에 로그인하면 받는 인증 토큰입니다. Windows가 제공하는 암호화(DPAPI)로 잠가서 저장하며 같은 PC의 같은 사용자 계정에서만 풀립니다. 비밀번호 자체는 받지도 저장하지도 않습니다. 로그인은 각 플랫폼 사이트에서 이루어집니다.

계정 표시 정보 화면에 어느 계정이 연결됐는지 보여줄 때 쓰는 표시 이름과 채널 식별자입니다.

OBS 서버 비밀번호 OBS 연동을 쓸 때만 저장합니다. 토큰과 같은 방식으로 암호화하며 화면에 다시 보여주지 않습니다.

프로그램 설정 프리셋, 적용 기록, 카테고리 검색 결과 캐시, 채팅 켜고 끔 설정 같은 사용 편의를 위한 값입니다.

저장 위치는 %APPDATA%\streamkit-plus 폴더입니다.

데이터 보호 방법

민감한 정보를 어떻게 지키는지 밝힙니다. 여기서 민감한 정보란 플랫폼 로그인 토큰, Google 사용자 데이터를 포함해 연동한 플랫폼에서 읽어오는 방송 정보와 실시간 채팅을 말합니다.

전송할 때 플랫폼 API와 주고받는 모든 통신은 HTTPS(TLS)로 암호화합니다. 암호화되지 않은 연결은 쓰지 않습니다. 로그인은 각 플랫폼 사이트에서 이루어지므로 프로그램은 아이디와 비밀번호를 받지도 보지도 않습니다. 로그인 결과를 돌려받는 임시 서버는 127.0.0.1에만 열려 있어 외부 네트워크에서는 접근할 수 없습니다.

저장할 때 인증 토큰과 OBS 비밀번호는 Windows 데이터 보호 API(DPAPI)로 암호화해 %APPDATA%\streamkit-plus\vault.bin 한 파일에 담습니다. 암호화 키는 해당 Windows 사용자 계정과 그 PC에 묶여 있어, 파일만 복사해 다른 PC나 다른 계정으로 옮기면 열리지 않습니다. 토큰을 평문으로 적어두는 곳은 없습니다.

프로그램 안에서 토큰은 플랫폼과 통신하는 부분에만 머무릅니다. 화면을 그리는 쪽으로는 넘기지 않으며, 화면은 연결 여부와 계정 표시 이름까지만 알 수 있습니다. 화면에 뜨는 오류 메시지에도 토큰을 담지 않습니다.

보관 기간 방송 정보와 채팅은 화면에 띄우는 동안만 메모리에 두고, 프로그램을 끄면 사라집니다. 파일로 남기지 않습니다. 토큰은 사용자가 연동을 해제하거나 프로그램을 지울 때까지만 남습니다.

접근 권한 제작자가 운영하는 서버가 없어 제작자는 이 정보에 접근할 수 없습니다. 제3자에게 제공하거나 판매하지 않으며, 사람이 열어보는 일도 없습니다.

정보가 나가는 곳

연동한 방송 플랫폼 사용자가 직접 연결한 플랫폼에만 요청을 보냅니다. 방송 제목과 카테고리, 태그를 바꾸거나, 현재 방송 정보와 채팅을 읽거나, 채팅을 보낼 때입니다. 유튜브, 트위치, 치지직, CIME이 여기에 해당합니다.

GitHub 새 버전이 있는지 확인하고 설치 파일을 내려받을 때만 접속합니다. 이때 사용자 정보는 보내지 않습니다.

OBS OBS 연동을 켜면 같은 PC 안에서만 연결합니다. 외부로 나가지 않습니다.

이 외의 곳으로는 아무것도 보내지 않습니다. 제3자에게 정보를 제공하거나 판매하지도 않습니다.

Google 사용자 데이터 취급

유튜브 연동에서 쓰는 권한과 데이터를 따로 밝힙니다.

요청하는 권한은 https://www.googleapis.com/auth/youtube 하나입니다. 이 권한으로 하는 일은 세 가지입니다.

  • 진행 중이거나 예약된 방송 정보를 읽습니다. 지금 걸려 있는 제목과 카테고리, 태그를 화면에 보여주기 위해서입니다.
  • 방송 정보를 바꿉니다. 사용자가 입력한 제목과 카테고리, 태그를 적용합니다.
  • 실시간 채팅을 읽고 보냅니다. 통합 채팅 화면에 띄우고 사용자가 쓴 내용을 전송합니다.

읽어온 방송 정보와 채팅은 화면에 보여주는 동안 메모리에만 있고 파일로 저장하지 않습니다. 저장하는 것은 인증 토큰뿐이며, 위 「데이터 보호 방법」에 적은 대로 Windows 암호화로 잠가 사용자 PC에만 둡니다. 전송 구간은 모두 HTTPS(TLS)로 보호합니다.

Google 사용자 데이터를 다른 사람이나 다른 서비스에 넘기지 않습니다. 제작자 서버로도 보내지 않으며 광고나 분석 목적으로 쓰지 않습니다. 사람이 열어보는 일도 없습니다.

StreamKit+가 Google API로 받은 정보를 이용하고 다른 곳에 전달하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

채팅은 저장하지 않습니다

채팅은 프로그램을 켠 뒤에 올라온 것만 화면에 보입니다. 메모리에만 두기 때문에 프로그램을 끄면 사라지며 파일로 남지 않습니다. 지난 채팅 기록을 불러오지도 않습니다.

플랫폼에서 받는 권한

로그인할 때 요청하는 권한은 기능에 필요한 범위로 제한합니다.

  • 방송 정보 읽기와 변경 — 제목, 카테고리, 태그를 바꾸려면 필요합니다
  • 채팅 읽기와 보내기 — 통합 채팅 기능에 필요합니다

각 플랫폼 계정 설정에서 언제든 연결을 끊을 수 있습니다.

정보를 지우는 방법

연동 해제 프로그램에서 플랫폼 아이콘을 우클릭해 연동을 해제하면 그 플랫폼의 토큰과 계정 정보가 지워집니다.

전체 삭제 프로그램을 제거한 뒤 %APPDATA%\streamkit-plus 폴더를 지우면 저장된 모든 정보가 사라집니다.

만 14세 미만 이용자

StreamKit+는 방송을 진행하는 이용자를 위한 도구이며 만 14세 미만을 대상으로 하지 않습니다.
