# StreamKit+

여러 방송 플랫폼에 **제목, 카테고리, 태그를 한 번에** 바꿀 수 있는 프로그램입니다.
유튜브, 트위치, 치지직, 씨미, 숲에 같은 방송을 동시에 켜는 분들을 위해 만들었습니다.
채팅도 한 화면에서 같이 볼 수 있습니다.

## 사용 방법

### 처음 시작

1. 설정에서 **실제 적용**으로 바꿉니다. 처음에는 연습 모드라서 눌러도 방송이 실제로 바뀌지 않습니다.
2. 위쪽 플랫폼 아이콘을 눌러 로그인합니다. 각 플랫폼 로그인 창이 브라우저로 열리고 로그인만 하면 끝입니다. 따로 키나 코드를 입력할 일은 없습니다.

### 방송 정보 바꾸기

- **제목** — 맨 위 칸에 쓰면 모든 플랫폼에 똑같이 들어갑니다. 특정 플랫폼만 다른 제목을 쓰고 싶으면 그 아래 플랫폼별 칸을 고치면 됩니다.
- **카테고리** — 게임 이름을 한 번만 적으면 플랫폼마다 알맞은 이름으로 맞춰줍니다. 예를 들어 "토크"라고 쓰면 트위치에는 Just Chatting, 치지직에는 talk으로 들어갑니다. 못 찾으면 직접 골라줄 수 있고 한 번 고른 건 다음부터 기억합니다.
- **태그** — 지금 걸려 있는 태그를 불러와서 보여줍니다. 여기서 새로 넣거나 뺄 수 있습니다.

다 정했으면 오른쪽 아래 **전체 적용** 버튼으로 한 번에 올립니다.

플랫폼 아이콘은 눌러서 이번 적용에 넣고 뺄 수 있습니다. 원래 색이면 이번에 적용되고 회색이면 빠집니다.

### 그 밖의 기능

- **채팅** — 여러 플랫폼 채팅을 한 곳에서 봅니다. 앱을 켠 뒤에 올라온 채팅만 보이고 여기서 답장도 보낼 수 있습니다.
- **프리셋** — 자주 켜는 방송 설정을 통째로 저장해두고 클릭 한 번으로 불러옵니다.
- **OBS 연동** — OBS에서 장면을 바꾸면 방송 제목·카테고리·태그가 자동으로 따라 바뀌게 할 수 있습니다.
- **이전 기록** — 적용할 때마다 직전 값이 저장돼서 언제든 예전 상태로 되돌릴 수 있습니다.

## 지원 플랫폼

| 플랫폼 | 로그인 | 제목 | 카테고리 | 태그 | 채팅 |
|---|---|---|---|---|---|
| 유튜브 | ✅ | ✅ | ⚠️ 큰 분류만 | ✅ | ⚠️ 사용량 주의 |
| 트위치 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 치지직 | ✅ | ✅ | ✅ | ✅ | ✅ |
| CIME | ✅ | ✅ | ✅ | ✅ | ✅ |
| SOOP | 준비 중 | — | — | — | — |

- 유튜브 채팅은 켜두면 하루 사용량이 빠르게 줄어듭니다. 필요할 때만 켜는 걸 권합니다.
- SOOP은 아직 준비 중입니다.

## 로컬 개발

Electron + React + TypeScript로 만들었습니다.

```bash
npm install       # 처음 한 번만
npm run dev       # 개발 모드로 실행
npm run build     # 빌드
npm run dist:win  # Windows 설치 파일 만들기
```

### 플랫폼 키

플랫폼 키는 `.env`에 넣습니다. `.env.example`을 복사해서 값을 채우면 됩니다.

비워둔 채로 빌드하면 사용자가 로그인 버튼을 눌러도 아무 일이 일어나지 않습니다.
등록되지 않은 앱에는 플랫폼이 동의 화면조차 띄우지 않기 때문입니다.
각 플랫폼 개발자 콘솔 주소는 `.env.example` 주석에 적어뒀습니다.

`npm run dev`로 띄우면 설정에 개발자 항목이 열려서 키를 직접 넣어볼 수 있습니다.
이 항목은 배포본에서는 나오지 않습니다.
