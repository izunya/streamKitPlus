StreamKit+
개인정보 처리방침 이용약관

여러 방송 플랫폼을 한 곳에서

StreamKit+는 유튜브, 트위치, 치지직, CIME에 방송 제목과 카테고리, 태그를 한 번에 적용하는 Windows 프로그램입니다. 채팅도 한 화면에서 보고 보낼 수 있습니다. 같은 방송을 여러 곳에 동시에 켜는 분들을 위해 만들었습니다.

다운로드

무엇을 할 수 있나요

방송 정보를 한 번에 바꾸기

제목, 카테고리, 태그를 한 화면에서 입력하면 선택한 플랫폼 전부에 올라갑니다. 플랫폼마다 사이트를 열어 같은 내용을 네 번 입력할 일이 없어집니다. 특정 플랫폼만 다른 제목을 쓰고 싶다면 그 칸만 따로 고치면 됩니다.

카테고리 자동 맞춤

같은 게임인데 플랫폼마다 이름이 다른 경우가 많습니다. 게임 이름을 한 번만 적으면 각 플랫폼에 맞는 카테고리를 알아서 찾아줍니다. 예를 들어 "토크"라고 쓰면 트위치에는 Just Chatting, 치지직에는 talk으로 들어갑니다.

통합 채팅

여러 플랫폼의 채팅을 한 화면에서 봅니다. 답장도 여기서 보내며, 보낼 곳을 여러 개 고르거나 전부를 선택해 한 번에 보낼 수 있습니다.

프리셋과 OBS 연동

자주 켜는 방송 설정을 프리셋으로 저장해두고 클릭 한 번으로 불러옵니다. OBS에서 장면을 바꾸면 걸어둔 프리셋이 자동으로 적용되게 할 수도 있습니다.

이전 기록과 되돌리기

적용할 때마다 직전 값이 함께 저장됩니다. 잘못 올렸을 때 되돌리기 한 번이면 이전 상태로 돌아갑니다.

데이터를 어떻게 다루나요

StreamKit+는 제작자가 운영하는 서버가 없습니다. 로그인 토큰은 Windows 암호화(DPAPI)로 잠가서 사용자 PC에만 저장하며, 제작자에게 전달되지 않습니다. 이용 기록을 모으는 분석 도구나 광고도 없습니다.

자세한 내용은 개인정보 처리방침과 이용약관에서 확인하실 수 있습니다.

설치

Windows 10 이상에서 동작합니다. 최신 릴리스에서 설치 파일을 내려받아 실행하세요. 새 버전이 나오면 프로그램이 알아서 받아 설치합니다.
